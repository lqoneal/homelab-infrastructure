# ZDCL-01 WOP Contract

`WOP-ZDCL-01-FOUNDATION-001` is the authoritative preparation and execution
package for the first ZDCL increment. Its scope is bounded to native session
identity, classification, repository and development-baseline verification,
evidence capture, and interruption-safe closeout.

The package is bound to `OB-PLAN-v1.0.0` and the canonical `homelab` repository.
`OA-v1.0.0` is immutable production state and is explicitly excluded. ZDCL-02,
CAGF, EPE, distributed execution, and runtime deployment are outside scope.

The canonical schema and execution-interface rules are defined in
`engineering/docs/architecture/WOP-SCHEMA-AND-EXECUTION-INTERFACE.md`.

The package is submitted through the existing Stage 1 authority. Submission
stages only; admission and execution remain protected, separate boundaries.
