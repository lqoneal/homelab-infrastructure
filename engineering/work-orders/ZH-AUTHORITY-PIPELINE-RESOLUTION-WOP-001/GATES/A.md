# Gate A — Canonical Repository and State Inventory

Verify before changing. Inventory repository identity, worktrees, duplicate
trees, EOS/runtime/staging/shared/recovery/archive paths, configured services,
process working directories, writers, consumers, divergence, and recovery.
Do not delete. Exit only with no unclassified Homelab path or unexplained
writable duplicate. Rollback: inventory artifacts can be withdrawn; external
state remains untouched and fail-closed.
