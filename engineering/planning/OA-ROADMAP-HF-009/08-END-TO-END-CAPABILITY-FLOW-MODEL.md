# End-to-End Capability Flow Model

Status: `PROPOSED INTEGRATION — NON-AUTHORITATIVE`

```text
Authority Resolution → Mission Planning → Mission Selection → WOP Resolution → Admission
→ Engineering Work Initiation → Dispatch → Execution → Observation → Evidence Collection
→ Qualification → Acceptance → Closeout
                           ↘ Synchronization → Reconciliation ↗
```

Synchronization operates at every published boundary; reconciliation is a corrective projection path that rejoins before closeout. It is not a lifecycle or authority cycle because it never changes the authoritative source or recreates a predecessor. The start is a resolved authority record, and the terminal capability is closeout after acceptance and reconciliation. These dependencies reuse HF-005’s validated state model and gate positions.
