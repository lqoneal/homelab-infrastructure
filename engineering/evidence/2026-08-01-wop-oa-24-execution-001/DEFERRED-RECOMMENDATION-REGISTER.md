# Deferred Recommendation Register

The following remain deferred because they require a separately governed
freshness, invalidation, or engineering-platform authority contract:

- persistent cross-request presentation caching;
- background projection materialization;
- filesystem-watch based invalidation;
- ZDCL, CAGF, EMP, EENS, distributed execution, and engineering automation.

No deferred recommendation is an OA-25 implementation artifact.
