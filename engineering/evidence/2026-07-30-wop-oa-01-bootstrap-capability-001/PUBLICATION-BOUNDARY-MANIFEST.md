# Bootstrap Capability Publication Boundary

## Included

This publication contains only the OA-01 bootstrap capability framework:

- controlled Authority Record, Operational Gate Plan, and Activation Record schemas;
- `OPERATIONAL-ALPHA-CONTROLLED-ARTIFACT-FRAMEWORK@1.0` and EMM registrations;
- `WOP-OA-01-ROOT-ADMISSION-001@2` and gate-action specification revision 2;
- controlled-document and execution-interface reconciliation;
- runtime candidate/validation support and the authoritative current-state status resolver;
- focused tests and this evidence directory.

## Excluded

The AQR revision and HF-002 evidence, OA-01 reassessment, HF-001 through
HF-004 roadmap directories, and all unrelated working-tree content remain
uncommitted. No OA-01 Authority Record, Operational Gate Plan, Activation
Record, implementation WOP, or OA lifecycle transition is included.

## Stop conditions

Stop if any excluded path is staged, a source digest fails resolution, or
OA-01 is no longer `READY / NOT_STARTED`.
