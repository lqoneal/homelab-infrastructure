## GPDR Reconciliation

PROC-0008 deliberately does not declare GPDR a new controlled document class.
Until the documentation architecture assigns authoritative ownership, GPDR is
a decision-ready package or evidence view, or it references an authoritative
decision recorded through an existing class such as EGR. This prevents the
pending GPDR from approving itself.
