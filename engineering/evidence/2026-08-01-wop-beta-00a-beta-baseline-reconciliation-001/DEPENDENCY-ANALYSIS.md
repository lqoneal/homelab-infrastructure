# Dependency Analysis

Every increment must declare prerequisites, outputs, authority bindings,
qualification evidence, successor boundary, and rollback behavior. A successor
consumes only published qualified outputs. Missing, stale, conflicting, or
cyclic inputs fail closed.

The reconciled order is BETA-00A, then separately authorized ZDCL-01/CAGF-01
when independence is proved, then EPE-01 and qualified successors.
