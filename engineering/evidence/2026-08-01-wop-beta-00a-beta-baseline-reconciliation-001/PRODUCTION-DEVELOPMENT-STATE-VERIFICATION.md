# Production/Development State Verification

Production is the immutable `OA-v1.0.0` baseline. Beta planning is a separate
development candidate. No working-tree, local EOS, or unmerged Beta artifact
promotes itself to production. Promotion requires governed publication, merge,
EOS synchronization, platform validation, and completion evidence.

Rollback preserves Beta evidence and returns to the last qualified Beta
checkpoint or Alpha baseline. Alpha tags and receipts are never rewritten.
