Keep CAP-021 as the independently qualified authorization boundary and keep
CAP-022 as the separate OA-22 outcome. The controller should expose outcome
readiness explicitly so a completed prerequisite is not mistaken for completed
mission work.

- Generate capability prerequisite/outcome projections from one canonical
  authority source.
- Add a controller regression that distinguishes prerequisite availability from
  mission completion.
- Keep ZDCL, CAGF, EMP, EENS, and distributed execution deferred.
