# Runtime Integration Report

The operational authority envelope wires all convergence services at the
execution decision boundary: EMM receipt, generated artifact, EOS plan, EENS
event, EMP projection, and qualification result. Their direction is
authoritative-to-derived; no envelope member can write back to EMM, WOP, or
Authority Record. Existing EOS atomic projection and EENS append-only storage
remain the transport implementations used after separately authorized work.
