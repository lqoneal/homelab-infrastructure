# Stable Zeus Controller Architecture

OA-15 publication establishes the stable Zeus operator interface baseline. Mission projections resolve through the Mission Knowledge Model; capability status resolves through the Capability Registry; EMM supplies binding and drift validation; PROC-0006 supplies qualification determination; controllers remain read-only projections.

The shared presentation contract is human-readable by default, deterministic JSON for `--verify`, and structured JSON for `--json`. The controller inventory and cross-command qualification remain in `engineering/evidence/2026-07-31-wop-zeus-controller-mkm-reconciliation-001/`.
