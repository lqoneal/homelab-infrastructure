# Canonical Execution Identity Contract

For receipt-backed Development Stage 1:

```text
execution_id == Stage 1 transaction.instance_id
```

Dispatch `instance_id` and provider-selection `transaction_id` must equal that value. Admission, registration, assignment, receipt, mission, WOP, package, provider, and session IDs remain separate bindings. An operator execution argument is accepted only when equal to the canonical value.
