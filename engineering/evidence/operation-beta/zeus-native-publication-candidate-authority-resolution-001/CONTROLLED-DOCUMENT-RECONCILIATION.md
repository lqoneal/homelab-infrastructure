# Controlled-document reconciliation

The publication procedure and Zeus user guide now define mission-scoped
candidate authority, live Mission/WOP discovery, qualified multi-source union,
dependency checks, already-published and historical exclusion, exact
source-to-path traceability, deterministic replay, and fail-closed ambiguity.

The existing rules remain unchanged: dirty status is not authority, unrelated
work is preserved, machine-readable JSON is the automation interface, and
publication mutation remains behind the established approval boundary.
