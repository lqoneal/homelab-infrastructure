# Source classification

On the actual repository projection used for qualification, the resolver
discovered current lifecycle evidence manifests by exact Mission/WOP context.
It excluded unrelated CAGF-01 and other Operation Beta records. Preserved
historical records remain visible to the resolver as non-current sources and
are not selected solely because they remain in the worktree.

The final counts and exact paths are generated in `COMPLETION-REPORT.md` from
the live projection. The source digest binds each manifest content/context
digest, so a changed qualification record cannot silently reuse an old
classification.
