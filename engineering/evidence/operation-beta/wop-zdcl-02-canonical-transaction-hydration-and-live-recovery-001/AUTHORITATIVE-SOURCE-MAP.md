# Authoritative Source Map

| Field | Source |
|---|---|
| Transaction identity | Stored runtime record |
| Source/package identity | Validation and packaging receipts |
| Registration identity | Registration receipt |
| Provider/agent identity | Valid dispatch and provider-selection receipts only |
| Authority | Stored authority snapshot; absence remains unresolved |
| Repository identity | Published repository and protected baseline tags |
| Lifecycle projection | Ordered presence of stored receipts |

Hydration does not treat projections or missing historical fields as authority.
