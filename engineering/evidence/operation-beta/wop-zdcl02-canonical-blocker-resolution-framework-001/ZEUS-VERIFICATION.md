# Zeus Verification

Supported read-only commands are `zeus blockers`, `zeus blocker show <id>`, `zeus blocker verify <id>`, `zeus blocker resolve <id>`, `zeus blocker graph`, `zeus blocker history`, `zeus qualification`, `zeus publication`, `zeus readiness`, and bare `zeus verify`. All return the canonical decision or blocker projection and preserve fail-closed exit status 77 while active blockers remain.
