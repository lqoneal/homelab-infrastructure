# Defect Confirmation

`DEFECT_CLASSIFICATION=SUBMISSION_ROUTING_AND_AUTHORED_PROVENANCE_CONVERGENCE_DEFECT`

The old route selected P2 only when `--repository` was absent and otherwise fell into the legacy admission-record path, where `--approval` was required. The source also lacked the Phase-1 traceability sidecar. The corrective now classifies the resolved source before option handling. A valid Development source is promoted with preserved identity and bytes; explicit package directories remain compatibility inputs.

Generic legacy approval is not execution authority. Submitted-WOP authority is preserved, and approval gates declared inside a WOP remain downstream controls.
