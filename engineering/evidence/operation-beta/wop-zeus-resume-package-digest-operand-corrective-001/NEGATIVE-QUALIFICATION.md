# Negative Qualification

PASS for disposable fail-closed cases:

- predecessor package binding mismatch;
- successor package binding mismatch;
- modified Stage 1 package digest;
- source digest mismatch;
- unrelated, broken, ambiguous, and circular lineage;
- stale, dirty, or unpublished resume environment.

Submission, projection, and runtime-state integrity remain independently
validated; none is accepted as package identity.
