# Fail-Closed Verification

Recovery rejects missing, unreadable, corrupt, path-escaping, identity-divergent,
ephemeral, or ambiguously discovered native threads. Immutable Zeus mission,
WOP, execution, execution-session, provider, provider-session, invocation, and
repository bindings are checked before mutation. Native responses must return
the expected thread ID, root session lineage, rollout path, and repository
`cwd`.

Another live wrapper claiming the thread blocks replacement. Operator approval
is required for stopped-transport recovery. Native request rejection causes the
newly launched transport to be terminated before session commit. The request
sequence contains no `thread/start` fallback. Fork requires an explicit option
and verified native lineage.

Live acceptance exercised the real Zeus command with approval. It returned
`THREAD_RECOVERY_BLOCKED` before launch because the recorded rollout and native
thread index entry are absent. PIDs `3417114` and `3417129` remained stopped.
No new wrapper, native thread, turn, work flag, runtime receipt, publication, or
EOS synchronization was produced.
