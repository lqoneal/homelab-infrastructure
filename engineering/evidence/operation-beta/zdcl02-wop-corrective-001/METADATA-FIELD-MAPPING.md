# Metadata Field Mapping

| Contract | Canonical owner | Producer | Consumers | Persistence/validation | Extension strategy |
|---|---|---|---|---|---|
| WOP | TPL-0001/STD-0003 | WOP author/Zeus intake | admission, EMM, execution interface | submitted source; WOP validator | no duplicate authority fields |
| Mission | EMP/Operation Beta | mission controller | Zeus projections, evidence | roadmap/mission state | projection only |
| Mission Contract | STD-0003/Work Registry in its applicable domain | mission owner | discovery and assurance | registry | read-only projection when not authoritative |
| Authority Record | Engineering Governance/SPEC-0014 where applicable | Governance artifact framework | EMM/Zeus resolver | EMM source digest | never generated by provider |
| ETP | SPEC-0008 | Authorization Kernel/PROC-0004 | handoff and validation | resolved manifest | additive transaction requirements only |
| Execution Interface | `engineering/execution/execution-interface.yaml` | repository owner | engctl/Zeus routing | repository-controlled file | route, do not replace semantics |
| Provider | existing execution resource contract | provider registry/qualification | selector and inspection | qualified resource record | bounded resource metadata |
| Agent | Zeus capability qualification | capability resolver | admission/execution | admission record | no self-asserted authority |
| Receipt | producing component (provider, EENS, EOS, EMM) | producer | Zeus verifier/evidence | append-only receipt | preserve producer identity/digest |
| EOS | EOS | EOS services | Zeus preflight/sync | EOS state/evidence | read-only consumption here |
| EENS | EENS | event adapter | lifecycle observers | append-only events | retry by event identity |
| Zeus runtime | Zeus runtime owner | runtime controller | status/recovery | runtime state | derived projection only |
| Zeus admission | Zeus Stage 1/EMM boundary | admission service | execution controller | admission record | no source mutation |
| Zeus verification | controlled verification owner | verifier | operators/evidence | evidence report | result projection, not authority |

Duplicate semantics are rejected; source facts remain with their producer.
