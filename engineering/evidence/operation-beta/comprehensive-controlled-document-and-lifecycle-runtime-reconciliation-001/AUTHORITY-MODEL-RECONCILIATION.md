# Authority Model Reconciliation

Current converged rule: an operator-submitted WOP is evidence of authority for work explicitly contained in that WOP. A generic second corrective, implementation, execution, WOP-authorization, or operator approval is not required. Admission, identity, scope, provider, session, evidence, publication, synchronization, and closeout remain independent controls.

The WOP-declared approval gate remains an enforceable gate. Legacy `required_approvals` is admission-record metadata and mission-selection configuration in the compatibility path; it is not generic execution authority. The P2 boundary records `operator-submitted WOP` authority and `generic_second_approval_required=false`.

Current normative documents and focused authority tests agree. Historical OA, Beta, and legacy admission records are retained as immutable evidence and are not authority for new Development work.
