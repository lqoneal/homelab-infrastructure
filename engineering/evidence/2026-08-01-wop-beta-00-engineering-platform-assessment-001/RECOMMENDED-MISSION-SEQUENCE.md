# Recommended Mission Sequence

1. `WOP-BETA-01-ZDCL-FOUNDATION-001` — bounded native session foundation.
2. `WOP-BETA-02-CAGF-SOURCE-CONTRACT-001` — canonical source ownership and
   deterministic projection contract.
3. `WOP-BETA-03-EPE-CONTRACT-AND-STATE-001` — executable mission contracts,
   task graph, and state evaluation foundation.
4. `WOP-BETA-04-ZDCL-SESSION-RECOVERY-001` — durable session persistence and
   interruption recovery.
5. `WOP-BETA-05-CAGF-PROVENANCE-001` — cross-source identity, dependency,
   cycle, and provenance validation.
6. `WOP-BETA-06-EPE-TRANSACTION-LEDGER-001` — mission transaction and execution
   ledger foundation.
7. `WOP-BETA-07-EPE-VALIDATION-RECOMMENDATIONS-001` — dependency-aware
   validation and structured recommendation lifecycle.

This sequence is a recommendation from BETA-00, not an admission or
implementation authorization. Each WOP must resolve its own authoritative
objective and confirm the published predecessor boundary.
