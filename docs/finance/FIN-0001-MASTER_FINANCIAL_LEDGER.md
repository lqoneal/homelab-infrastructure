# Master Financial Ledger

## Purpose

This document is the authoritative financial summary for the engineering portfolio.

It provides the current financial position of engineering activities while referencing immutable procurement and transaction records for historical detail.

This document summarizes financial state and shall not duplicate record-level information maintained in procurement or transaction records.

---

# Authority

This document owns:

- Portfolio financial summary
- Engineering project expenditures
- Asset acquisition totals
- Financial reporting
- Cross-references to procurement and transaction records

Individual financial events are documented separately.

---

# Financial Governance

The Finance Domain follows five governing principles:

1. Financial records are evidence-backed.
2. Procurement records are immutable.
3. Transaction records are immutable.
4. Corrections create new records rather than rewriting history.
5. Master registers summarize rather than duplicate detailed records.
