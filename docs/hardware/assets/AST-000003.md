# Engineering Notes

This namespace is the 32 GB Optane portion of the same physical Intel Optane
Memory H10 module whose 1 TB NAND namespace is AST-000002. It has no partition
table or mounted filesystem and exposes Intel `isw_raid_member` metadata
(version 1.4.01). It is therefore platform/acceleration capacity, not qualified
free storage. SMART passed on 2026-07-16 with zero critical warnings,
media/data-integrity errors, or error-log entries. Clearing or repurposing its
metadata is not authorized.
